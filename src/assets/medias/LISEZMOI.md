# Médias du site

Déposez ici les images réelles, avec exactement ces noms (liste complète et consignes dans `src/data/medias.json`) :

| Fichier | Où | Format |
|---|---|---|
| `jerome-verger.jpg` | Qui je suis | Portrait, 1200 × 1200 px minimum |
| `exemple-maquette-audit.webp` | Audit offert | 16:10, 1600 px de large minimum |
| `capture-vue-dirigeant.webp` | Côté équipes et dirigeant | 16:10, 1600 px de large minimum |
| `capture-suivi-interventions.webp` | Réalisations | 16:10, 1600 px de large minimum |
| `capture-acces-membres.webp` | Réalisations | 16:10 |
| `capture-action-bouton.webp` | Réalisations | 16:10 |

- Floutez les noms, emails, téléphones et adresses de vos clients avant de déposer une capture.
- Le site convertit et redimensionne les images automatiquement (AVIF et WebP).
- Tant qu'un fichier est absent, son bloc est masqué sur le site publié.
- Pour voir les emplacements en local : `PUBLIC_AFFICHER_EMPLACEMENTS=true npm run dev`.
